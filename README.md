# Red PCC O’Higgins — reconstrucción temporal

Sitio estático reconstruido a partir de capturas de Internet Archive. Las páginas proceden de distintas fechas y algunos contenidos e imágenes aún no se han recuperado. Los enlaces sin copia local conducen a Wayback Machine.

La portada sigue principalmente la versión de marzo de 2025; los listados de proyectos y noticias integran versiones posteriores. Este sitio es una reconstrucción preliminar y no incluye el panel de administración ni las funciones dinámicas de WordPress.
